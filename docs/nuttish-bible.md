# Nuttish v1.0 — tiny language bible

Nuttish is the original house language of Nuts Games. It is playful, compact and deliberately understandable with light English context. It is not random gibberish.

## Sound

- Hard, percussive roots: `krak`, `nut`, `tik`, `pak`, `boom`.
- Friendly motion words end in `-a`: `skippa`, `rolla`, `wiggla`.
- Useful compounds are literal: `code-hole`, `nut-crew`, `secret-jar`, `old-shell`.
- Stress normally falls on the first syllable.

## Grammar

- Word order: subject–verb–object.
- No grammatical gender or articles.
- Plural is usually clear from context; add `-folk` for people and `-bits` for objects when needed.
- Past experience uses `old-shell`; current skilled action uses `kraka`; delivery uses `ship`.
- Negation is `no` before the phrase: `no blah-blah`, `no ghost crews`.
- Questions end with `-cha?` in ceremonial Nuttish, but plain question marks are acceptable in interface copy.

## Core vocabulary

| Nuttish | Meaning |
|---|---|
| kraka | skilled creative work; to make well |
| nut-crew | a right-sized production team |
| old-shell | experience earned over time |
| shiny / shinies | rewarding visual asset(s) |
| wiggle | animation |
| sniff / sniff-check | explore / review carefully |
| pile | scoped group of deliverables |
| coin pile | budget |
| code-hole | integration destination |
| paw-check | human review |
| secret jar | privacy and protected information |
| tail-zoom | squirrel intro animation |
| blah-blah | process without delivery value |
